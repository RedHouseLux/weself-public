# Publication Notes

This repository is intentionally limited to a public-facing overview of WeSelf.

It should not include:

- product source code
- internal architecture or deployment details
- business plans, pricing, fundraising, or partnership strategy
- signal logic, scoring rules, prompts, or AI behavior
- private PDFs, clinical documents, or compliance materials
- credentials, tokens, environment files, domains, or private contact flows
- screenshots containing user data, admin screens, dashboards, or partner names

Recommended GitHub description:

> A human-centered smart agenda for daily planning, reflection, and early wellbeing signals.

`wellbeing`, `mental-health`, `smart-agenda`, `reflection`, `journaling`, `human-centered-ai`, `preventive-care`
